# Publier

Front statique + fonction `/api/publish` sur Vercel, fichiers et historique sur Supabase.

Variables d'environnement Vercel : `PAGE_ID`, `PAGE_TOKEN`, `APP_PASSWORD`.

Pages : Accueil (stats + alertes), Publier, Publications, Commentaires, Historique.
Autorisations du token : pages_show_list, pages_read_engagement, pages_manage_posts, read_insights, pages_read_user_content, pages_manage_engagement.
